# Data

Everything in this project is **synthetic** or **authored**. There is no real patient data.

- `synthetic/` is generated by `cliniq generate` (seed 42, 1,200 patients; git-ignored). It contains FHIR R4 bundles, an LIS lab CSV feed, a genomic vendor CSV feed, notes JSONL, `manifest.json` (counts and the exact injected-fault ledger), and `truth.json` (latent attributes, never ingested).
- `demo/demo_upload_bundle.json` is a 1-patient FHIR bundle used in the demo walkthrough. It contains one deliberately implausible lab value, which ends up in the dead-letter queue.
- `corpus/reference/` holds 14 authored reference notes (CC-BY-4.0, not peer-reviewed).
- `corpus/trials/` holds 28 synthetic trial eligibility documents, generated by `cliniq bootstrap`.
- `corpus/ctgov/` (optional) holds real public trials fetched with `scripts/fetch_ctgov.py`.
