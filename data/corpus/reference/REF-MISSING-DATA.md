# Missing data in real-world cohort feasibility

AUTHORED REFERENCE NOTE — a short summary written for this demonstration from general domain knowledge. Figures are approximate and are not a substitute for primary literature or clinical guidance.

Real-world clinical data are collected for care, not research, so the absence of a record is not the same as evidence that a condition is absent. A useful distinction is between negative evidence (for example, a biomarker test reported as not detected), absent evidence (the patient has records in a domain but none matching the criterion), and unknown status (no data in that domain at all). Feasibility estimates should report how many otherwise-eligible patients are blocked only by unknown information, because those patients could become eligible after chart review or additional testing.
