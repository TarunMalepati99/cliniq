# CLINIQ API reference

Generated by `scripts/make_api_docs.py` from the FastAPI app. Interactive docs: `http://localhost:8000/docs`.

Authentication: `Authorization: Bearer <token>`. Roles: viewer < researcher < admin. Long-running operations (ingest, dbt, reindex, DLQ retry, benchmarks) return **202** with a `job_id`; poll `GET /api/jobs/{job_id}`. Pass `?wait=true` to run them synchronously. Every response carries an `X-Request-ID` header.
